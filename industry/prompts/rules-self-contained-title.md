
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：船司 / 航司 / 港口 / 航线 / 指数 / 公司名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是周次 / 航线代码 / 没信息量的 teaser（如 "Week 42"、"Service update"、"重要通知"）时，结合【来源】和正文把主体补进标题。例：原标题 "Week 42" + 来源 "Maersk Advisory" + 正文写明综合费率上调 → "马士基公布第 42 周综合费率上调"。正文没有写上调，就不要把标题写成上调。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体航线时，用上位词（如"亚欧航线"）兜底，绝不凭"行业常识"编一个航线代码、指数点位、港口或涨幅。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析、实务或评述标题，中文标题必须保留这个类型；不能因为正文谈到一次已经存在的空班、运价或新数据，就改写成“宣布 / 上调 / 空班 / 生效”。只有原标题明确宣布了调整、上调、空班或生效，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、航线、港口名。
   例：原标题 "How the Red Sea diversion changes Asia–Europe transit times" → "红海绕行如何改变亚欧航程"，不能写成 "船司宣布红海绕行"。
   例：原标题 "How to amend a bill of lading after a transshipment change" + 来源和正文明确是某货代的操作说明 → "某货代说明转运变更后如何改提单"，不能只写成缺主体的 "如何改提单"。
6. 本条的动作和背景里的旧调整要分清：原文把调整写成过去的事（“Last week we blanked …”“上周我们已空班…”），本条是在讲改配、做说明或再次提醒时，标题写说明、改配或讲解，把空班或涨价交代成此前的事；不能写成“宣布空班 / 上调运价”，否则读者会当成今天的新调整。只有原文明确某项附加费或窗口是现在才生效，才对那一项用对应动作。
   例：正文 "Last week we blanked two FE2 sailings. Here is how to rebook." → "船司说明上周 FE2 两条空班后的改配做法"，不能写成 "船司宣布 FE2 空班"。
